- Godot 工程：`sandbox/`（1920×1080，gl_compatibility）

## 三、已知缺口（如实）

| 缺口 | 原因 | 证据 |
|---|---|---|
| 绝对坐标 | 无可用地图/传送点数据源 | 多次探测：米游社接口失效、开源库只有宝箱/怪物点、小地图无位移信号 |
| 战斗识别 | 素材缺持续战斗片段；血条启发式失败 | 5.7 深渊视频战斗仅数秒，其余为菜单 |
| VLM | 模型下载网络不可行（0.02MB/s） | ollama.com 重置、GitHub 极慢、代理失效；客户端代码已就绪 |
| 三维精确回放 | 依赖绝对坐标 | 当前仅示意坐标 |
| 真实环境执行 | 文档边界内不做 | 需要授权测试环境 |

## 四、快速开始

```powershell
# 方向一：校验/统计/复核/查看器
$env:PYTHONPATH = "D:\OpenAI\GenshinGuideAI\src"
python -m ggai validate runs\p002_full_v7.json
python tools\make_review.py runs\p002_full_v7.json runs\review.csv
python tools\build_viewer.py runs\p002_full_v7.json --out runs\viewer_p002

# 方向二：沙盘（路线 / 证据 / 执行）
$gd = "D:\OpenAI\GenshinGuideAI\tools\godot\Godot_v4.7.2-stable_win64_console.exe"
& $gd --path D:\OpenAI\GenshinGuideAI\sandbox -- --route
& $gd --path D:\OpenAI\GenshinGuideAI\sandbox -- --seek=100
& $gd --path D:\OpenAI\GenshinGuideAI\sandbox -- --exec

# 方向三：分支评估与执行归档
python tools\run_branches_multi.py --seeds 20
python tools\archive_exec.py --result sandbox\data\exec_result.json

# 全量测试
python -m unittest discover -s tests
```
