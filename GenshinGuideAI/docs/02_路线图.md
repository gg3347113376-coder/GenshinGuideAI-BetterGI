- 验收：文档 `00_范围与决策.md` 通过评审。

## P1 统一数据协议 v1（已完成）

- 验收：样例项目校验通过；入库→导出→再校验一致；6/6 单元测试通过。

## P2 方向一 MVP：单视频 → 可追溯事件（进行中）
目标：选一段 20–40 分钟、含跑图+战斗+NPC 交互的真实视频，产出协议 v1 JSON。

拆解：
1. 视频接入：PyAV/FFmpeg 解码、元数据、SHA-256、场景切分（镜头变化 + 固定间隔兜底）。
2.HUD 区域识别：小地图、任务追踪、字幕、对话框、血条；先固定 1920×1080 比例区域，后续做自适应。
3. OCR：PaddleOCR / Umi-OCR，输出文本 + 框 + 时间戳；对话与任务追踪分别入库。
4. ASR：faster-whisper 转写解说（可选，作为旁证）。
5. 事件抽取：规则优先（出现对话 UI → dialogue；出现选项 → dialogue_choice；血条/技能 CD → 战斗；小地图位移 → move）。
6. 位置估计：小地图模板匹配 + 玩家箭头定位，输出 map x/y（未知则 null）+ error_m。
7. VLM（Qwen3-VL 4B）：只对关键帧做语义确认（场景/动作类别），失败可跳过，不阻塞主流程。
8. 人工纠正：最小 Web 界面（或 CSV 导出→改→回填），保留修改前后。
9. 导出协议 JSON + 指标统计。

验收：
- 真实视频输出 ≥ 50 条有序事件，每条有证据时间戳；
- 人工抽检 30 条，动作类型正确率 ≥ 80%（首版目标，非终值）；
- 位置事件中「有坐标/未知」标注 100% 合规（不编造）；
- 中断后重跑不重复、不丢已完成结果。

## P3 方向二 精确回放 MVP
- Godot 4 项目：局部地形（复用纳塔 OBJ）+ 导航网格 + 角色 + 交互区；
- 导入 P2 JSON，按时间线回放路线/动作/交互；
- 暂停/单步/倍速/跳转，状态快照恢复；
- 不确定事件显示标记；导出偏差报告。

验收：回放与原视频时间线对齐；跳转后状态正确；缺口显著标记。

## P4 误差验证
- 人工标注对照集（≥ 5 分钟片段）；
- 指标：定位覆盖率、位置误差（中位数/90 分位）、动作 P/R/F1、OCR 错误率、事件时间误差；
- 输出测试报告（含样本、方法、置信区间说明）。

## P5 自由推演
- 分支存储（初始状态、参数、规则版本、随机种子、修改、结果）；
- 约束检查（层级、碰撞、可达性）；
- 新旧方案对比报告。

## P6 方向三 沙盘闭环执行
- 战略/战术/执行/安全监督四层；
- 每步字段：任务/步骤/目标/前置/参数/预期/超时/重试/失败策略/风险级别/授权/证据/日志；
- 故障注入：位置偏差、障碍、目标变化、操作丢失、超时、中途退出；
- 指标：首次成功率、纠错成功率、漏检/误报率、恢复时间；人工急停与审计回放。
