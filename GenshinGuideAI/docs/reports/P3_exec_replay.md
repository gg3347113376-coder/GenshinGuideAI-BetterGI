# P3/P6 执行结果回放（Godot 三维）

- 日期：2026-11-06
- 数据：方向三模拟执行器输出的审计轨迹
- 截图：`docs/reports/sandbox_replay.png`

## 数据链路

```
方向一事件 JSON
   → plan_builder 生成示意计划
   → 模拟执行器（A* + 纠错 + 安全监督）执行
   → 审计日志 runs/exec_audit.jsonl
   → 导出 sandbox/data/exec_replay.json
   → Godot 回放（轨迹点 + 移动标记 + HUD）
```

回放文件结构：

```json
{
  "project": "P002 v6",
  "note": "网格坐标示意回放；不是视频真实坐标",
  "steps": [
    {"tick": 1, "step": "evt_000", "action": "move", "status": "ok", "pos": [3, 3]},
    ...
  ]
}
```

## Godot 回放实现

| 能力 | 说明 |
|---|---|
| 模式切换 | R 键在「执行回放」与「路线视图」间切换 |
| 轨迹 | 每步一个小绿球 + 连接线；当前步用橙色发光球 |
| 镜头 | 按轨迹包围盒自动取景 |
| HUD | 项目名、进度 n/N、动作、状态、网格坐标、“网格示意，不是视频真实坐标” |
| 隔离 | 回放时隐藏路线节点、角色与导航层，避免干扰 |

验证输出：

```
REPLAY steps=20 project=P002 v6
REPLAY t=0.3 idx=1/20
REPLAY t=... idx=6/20
```

## 边界

1. 坐标是**网格示意坐标**，不是视频中的真实游戏坐标；
2. 回放的是模拟执行器的轨迹，不是真机操作；
3. 这一步证明的是「执行结果可以回放到三维场景」，而不是「真实跑图可复现」。
