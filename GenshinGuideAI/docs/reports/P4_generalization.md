## 三、结论

1. **结构层面泛化良好**：事件密度、对白占比、说话人比例（90% vs 91%）、证据覆盖（均 100%）都稳定；
2. **文本质量在第二支视频上更好**（可疑标记 1.6% vs 23.5%），说明 P002 的高标记率主要来自其长对话与专名密度，不是管线缺陷；
3. **没有 P001 的人工金标准**，因此只做结构对比，不宣称文本准确率；
4. 移动事件从 4 增到 21，说明任务追踪变化检测在赶路场景更活跃，符合预期。

## 四、限制

- 两支视频都来自同一 UP 主、同一 5.0 UI 版本，未测 4.x/6.x 的 UI 差异；
- 未覆盖 21:9、窗口化、低分辨率等录制差异；
- P001 只有 14.5 分钟，样本偏短。
