## 一、方法与参数

| 环节 | 实现 |
|---|---|
| 解码采样 | PyAV，逐帧解码，1 fps 采样（300 帧） |
| OCR | RapidOCR（ONNX，CPU），**固定条带 + 免检测识别**：任务追踪 3 条带、字幕 6 条带 |
| 文本归一化 | 去空白、去首尾标点、相似度（SequenceMatcher）去重 |
| 稳定性 | 同一文本连续 2 个采样才发射；最近 3 条内相似度 ≥0.9 不重复发射 |
| 任务追踪 | 任务名/小标题与距离分离；10 秒记忆补齐，避免条带漏检抖动 |
| 事件规则 | 任务文本变化 → `move`；字幕变化 → `dialogue`（区分说话人/台词） |
| 证据 | 文本变化帧存 JPEG；每条 OCR 证据带时间戳与 bbox |

## 三、已知问题（按优先级）

1. **OCR 噪声**：台词首尾偶发「一」「人」等误识别；`「古名」` 等专名有错字。
2. **说话人误判**：36 条中约 4 条说话人错误（如“人森珀娅”“沙博蒂”“更像是全民运动会”），原因是短句被当成说话人。
3. **任务文本抖动**：已从 9 条压到 3 条，仍有 1 条“深入纳塔一 | 深入纳塔”属噪声。
4. **没有位置数据**：本期未做小地图定位，`move` 事件全部无坐标（符合协议，但没有定位覆盖率）。
5. **没有战斗事件**：未做血条/技能 CD/战斗起止识别。
6. **样本覆盖**：仅 5 分钟，尚未跑完整 27 分钟，也未做人工标注对照。
