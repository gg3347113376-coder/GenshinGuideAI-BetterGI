# 双模式回放（证据回放 / 连续演示）

- 日期：2026-11-06
- 实现：`sandbox/main.gd` 执行回放模式
- 截图：`docs/reports/dual_exact.png`、`docs/reports/dual_continuous.png`

## 一、两种模式

| 模式 | 行为 | 标注 |
|---|---|---|
| 证据回放（默认） | 标记**精确落在**每个执行步骤的位置，不做插值 | HUD：`模式：证据回放（精确跳转）` |
| 连续演示 | 在两个步骤位置之间按时间插值移动，画面更连贯 | HUD：`模式：连续演示（沙盘补全）` |

切换：`C` 键；启动参数 `-- --continuous` 可直接进入连续模式。

## 二、对照证据

同一段动画、同一帧（第 22 帧）：

- 证据回放：橙色标记落在绿色轨迹点上（完全对齐步骤位置）；
- 连续演示：橙色标记位于两个轨迹点之间，且 HUD 明确标注「沙盘补全」。

这样满足文档要求：**证据回放不擅自补动作；连续演示允许平滑过渡，但必须标识为沙盘补全**。

## 三、实现要点

1. 轨迹点来自执行审计（每步位置 + tick）；
2. 连续模式按 `(replay_t - t0) / (t1 - t0)` 插值；
3. 模式文字随状态切换，避免把补全当证据；
4. 顺带修复了模式可见性 bug：回放时错误显示路线/证据面板，统一由 `_apply_visibility()` 按模式控制。

## 四、验证

```
REPLAY steps=20 project=P002 v6
REPLAY_CONTINUOUS=true
REPLAY t=0.3 idx=1/20
```

无头模式运行无脚本错误；两种模式各渲染 45 帧并抽帧对比。

## 五、边界

- 插值只发生在**示意网格坐标**上，不是真实游戏路径；
- 连续模式只是视觉平滑，不代表真实动作被还原；
- 证据回放的“精确”指与执行记录一致，不是与视频画面逐帧对齐。
