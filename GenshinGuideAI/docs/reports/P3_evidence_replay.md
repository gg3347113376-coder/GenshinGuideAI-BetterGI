# 沙盘证据回放（视频时间对齐）

- 日期：2026-11-06
- 工具：`tools/export_evidence.py` + Godot `evidence_mode`
- 截图：`docs/reports/sandbox_evidence.png`

## 一、数据链路

```
项目 JSON（含证据帧）
  → export_evidence.py 复制证据帧到 sandbox/data/evidence_frames/
  → evidence.json（事件 + 视频时间 + 帧相对路径）
  → Godot 证据模式：按视频时间推进，显示当前事件的证据帧
```

导出结果：196 条事件、196 张证据帧、`evidence.json` 40.2 KB。

## 二、Godot 证据模式

| 能力 | 说明 |
|---|---|
| 证据帧显示 | Sprite3D 挂在相机前（pixel_size 0.0024，距离 3.2），作为三维场景中的“证据面板” |
| 时间推进 | 按事件的 `video_time.start_s` 推进，1 秒视频时间对应 1/4 秒回放（4×） |
| HUD | 项目名、视频时间、事件 n/N、类型、说话人、文本 |
| 模式切换 | E 键在「证据回放 / 路线视图」间切换；R 键进入执行回放 |
| 隔离 | 证据模式下隐藏路线节点、角色与执行轨迹 |
| 按需加载 | 纹理懒加载并缓存，避免一次载入 196 张图 |

## 三、验证

```
EVIDENCE events=196 project=P002 v6
EVIDENCE t=0.6 idx=1/196
EVIDENCE t=3.9 idx=1/196
```

截图可见：证据帧中派蒙字幕「至少说明我们走对了！」、任务追踪「纳塔！新的旅程 / 深入纳塔」；HUD 显示视频时间 8.1s、事件 4/196。

## 四、边界

1. 证据帧是**平面面板**，贴在相机前，不是把视频投影到三维地形上；
2. 视频时间与仿真时间没有建立坐标对应（没有位置数据），只是并排呈现；
3. 采样为 1 fps，事件时间精度约 ±1 秒；
4. 这是“证据回放”，不是“精确三维重现”。

## 五、回放控制（本轮新增）

| 操作 | 行为 |
|---|---|
| 空格 | 暂停 / 继续 |
| ← / → | 上一条 / 下一条事件（同时把视频时间跳到该事件） |
| ↑ / ↓ | 调速（0.5×–64×） |
| E | 切换证据/路线视图 |
| 启动参数 | `-- --seek=N` 直接跳到第 N 条事件 |

HUD 现在显示：视频时间/总时长、事件序号、当前速度、暂停标记与操作提示。
