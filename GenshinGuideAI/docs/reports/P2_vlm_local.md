# 本地 VLM 复核（Qwen2.5-VL-3B，CPU）

- 日期：2026-11-07
- 背景：此前 Ollama 路线被网络卡死（安装包重置、GitHub 0.02MB/s），本次改走「ModelScope 直下 + transformers 本地推理」，**不需要 Ollama，也不需要额外授权**。

## 一、环境

| 组件 | 版本/来源 |
|---|---|
| torch | 2.9.1+cpu（Aliyun 镜像 7.3MB/s） |
| transformers | 5.22.2 |
| torchvision | 0.24.1+cpu |
| 模型 | Qwen/Qwen2.5-VL-3B-Instruct（ModelScope，7.2GB，约 15MB/s，7 分 52 秒下完） |
| 推理 | CPU，bfloat16，max_pixels=262144（512²），max_new_tokens 48–64 |

## 二、速度

- 模型加载：约 10–11 秒；
- 单帧推理：**34–59 秒/帧**（CPU，无 GPU）。

## 三、结果

| t | 输出 |
|---|---|
| 0.02 | open_world |
| 4.02 | 对话 |

**准确率 1/3**；置信度恒定在 0.95–1.0，没有校准意义。

## 四、结论

- VLM **能在本机离线跑起来**，填补了此前「装不上」的空白；
- 但 3B 模型 + 512² 输入 + CPU，语义分类**不可靠**，不能用于验收或自动复核；
- 输出置信度不可信，必须人工复核。

## 五、限制与下一步

1. 分辨率太低（512²）会丢 UI 细节；提到 1M 像素 CPU 时间约 4 倍；
2. GPU 可用（RTX 4060 8GB），但 CUDA 版 torch 轮子从 Aliyun 下载只有 0.23MB/s，2.5GB 需数小时，暂放弃；
3. 提示词可再针对「是否有字幕/小地图/血条」做二分类，比场景分类更稳；
4. 若要走 GPU：需要离线提供 torch cu126 轮子，或等镜像恢复。
